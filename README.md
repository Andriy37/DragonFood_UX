# 🐉 Dragon Food — Веб-сервіс доставки їжі (Варіант № 25)

Повнофункціональний адаптивний SPA та PWA-застосунок для онлайн-замовлення та доставки їжі з ресторанів.

## 🌐 Посилання на проєкт
- **Репозиторій GitHub:** https://github.com/Andriy37/Dragon_Food
- **Live-демо (Vercel):** https://dragon-food.vercel.app

## 🛠 Технологічний стек
- **Frontend:** React, Vite, React Router, Context API, Custom Hooks (`useFetch`), CSS3 Design Tokens (Light/Dark Theme), PWA (`manifest.json` + Service Worker).
- **Backend:** Node.js, Express.js, REST API (CRUD), файлове сховище JSON (`fs/promises`), серверна валідація.
- **QA & SEO:** Vitest, React Testing Library, Google Lighthouse (95+ балів), Schema.org JSON-LD, `robots.txt`, `sitemap.xml`.
